WhatsAppBot (Better name pending)

WhatsAppBot is a selenium script using python that was made during my internship to automate sending, reading, and receiving messages on WhatsApp. The WhatsAppBot application/script is integrated with MySQL, and has a user interface using Tkinter. It also has an additional sub web application made using laravel to display the data from the MySQL database in realtime, originally intended to streamline the flow of information.

Selenium

This project was developed using selenium a popular, open-source suite of tools designed for automating web browsers. It is primarily used for testing web applications to ensure they function as expected across various browsers, platforms, and operating systems.

MySQL

This project uses MySQL as its primary relational database management system to store and manage message logs, user data, scheduling information, and bot activity records. MySQL enables reliable data persistence, structured querying, and efficient retrieval of real-time communication data required by the automation workflow.

Laravel

The Laravel sub-application serves as a web-based dashboard that visualizes and monitors the data stored in the MySQL database in real time. Built using the Laravel PHP framework, it provides a structured MVC architecture, enabling easier data management, reporting, and streamlined access to WhatsAppBot operational insights.
